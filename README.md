# Cybersecurity resources

A collection of tools, lookup services and labs for security analysts, researchers, bug bounty hunters and fellow weirdos.

## Security distributions and workstations

- [Kali Linux](https://www.kali.org/) - Debian-based distribution with penetration testing tools.
- [Parrot OS](https://parrotsec.org/) - Debian-based distribution for security testing and privacy.
- [BlackArch](https://blackarch.org/) - Arch Linux repository and distribution for security research.
- [Pentoo](https://www.pentoo.ch/) - Gentoo-based live Linux environment for security testing.
- [Commando VM](https://github.com/mandiant/commando-vm) - Windows workstation setup for penetration testing.
- [FLARE-VM](https://github.com/mandiant/flare-vm) - Windows workstation setup for malware reverse engineering.
- [SIFT Workstation](https://www.sans.org/tools/sift-workstation/) - Forensic workstation for examining disks, memory and timelines.
- [REMnux](https://remnux.org/) - Linux workstation for malware analysis.

## Privacy-focused operating systems

- [Qubes OS](https://www.qubes-os.org/) - Desktop OS that isolates applications in separate virtual machines.
- [Whonix](https://www.whonix.org/) - Two-VM operating system that routes workstation traffic through Tor.
- [Tails](https://tails.net/) - Portable live OS for private browsing through Tor.

## Coordinated vulnerability disclosure

- [Zero Day Initiative](https://www.zerodayinitiative.com/) - Program that coordinates vulnerability reports with affected vendors.

## Vulnerability tracking and prioritization

- [CVE Details](https://www.cvedetails.com/) - Search CVEs by product, vendor or vulnerability type.
- [CVE Program](https://www.cve.org/) - Official registry of CVE identifiers and vulnerability records.
- [OpenCVE](https://www.opencve.io/) - Track new and updated CVEs for selected products.
- [NIST National Vulnerability Database](https://nvd.nist.gov/vuln/search) - Search CVE records, severity scores and affected software.
- [CIRCL Vulnerability-Lookup](https://vulnerability.circl.lu/) - Search and correlate vulnerability reports from multiple sources.
- [CISA Known Exploited Vulnerabilities Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) - Check which vulnerabilities CISA has documented as exploited in the wild.
- [FIRST EPSS](https://www.first.org/epss/) - Estimate the probability of CVE exploitation in the next 30 days.

## Internet asset search

- [Shodan](https://www.shodan.io/) - Search internet-facing devices by service banner or network.
- [Censys](https://platform.censys.io/) - Search indexed hosts, certificates and web properties.
- [ZoomEye](https://www.zoomeye.org/) - Search internet-facing devices and web services by fingerprint.
- [HUNTER (hunter.how)](https://hunter.how/) - Search indexed internet services by protocol, product or certificate.

## Data analysis

- [CyberChef](https://gchq.github.io/CyberChef/) - Build browser-based recipes to decode, transform and inspect data.

## Malware sandboxes

- [Joe Sandbox](https://www.joesandbox.com/) - Inspect file behavior through automated sandbox reports.
- [ANY.RUN](https://app.any.run/) - Interact with suspicious files in a sandbox and observe their behavior.
- [Hybrid Analysis](https://hybrid-analysis.com/) - Search public sandbox reports or submit files for analysis.

## URL, file and hash analysis

- [VirusTotal](https://www.virustotal.com/) - Look up file hashes, URLs and domains across security engines.
- [Jotti](https://virusscan.jotti.org/) - Scan a file with multiple antivirus engines.
- [PolySwarm](https://polyswarm.network/scan) - Compare file verdicts from independent malware detection engines.
- [OPSWAT MetaDefender Cloud](https://metadefender.opswat.com/) - Scan files with multiple engines and look up hash reports.
- [Intezer](https://analyze.intezer.com/) - Analyze suspicious files and identify code shared with known malware.
- [urlscan.io](https://urlscan.io/) - Inspect a page’s screenshot, HTTP requests and contacted domains.
- [URLVoid](https://www.urlvoid.com/) - Check a website’s reputation across blocklists.
- [InQuest Labs](https://labs.inquest.net/) - Browse threat indicators and research on suspicious documents.
- [CyberGordon](https://cybergordon.com/) - Look up indicators across multiple threat intelligence sources.
- [YARAify](https://yaraify.abuse.ch/) - Scan files with YARA rules and search for rule matches.

## Threat intelligence

- [URLhaus](https://urlhaus.abuse.ch/browse/) - Look up URLs reported for distributing malware.
- [Intelligence X](https://intelx.io/) - Search indexed documents, historical web content and breach data.
- [Cisco Talos Intelligence](https://talosintelligence.com/) - Check IP, domain and email sender reputation.
- [X-Force](https://exchange.xforce.ibmcloud.com/) - Look up threat indicators in IBM’s intelligence platform.
- [ThreatMiner](https://www.threatminer.org/) - Explore relationships between domains, IP addresses and malware samples.
- [Open Threat Exchange (OTX)](https://otx.alienvault.com/) - Browse community reports and their associated indicators.
- [GreyNoise](https://viz.greynoise.io/) - Check whether an IP has been observed scanning the internet.
- [HEARTH](https://hearth.thorcollective.com/) - Browse community-contributed threat hunting ideas.
- [ICHI – Internet Cyber Health Index](https://ichi.global/) - Track a global cyber risk index alongside vulnerability and incident feeds.
- [Whatoblock](https://whatoblock.com/) - Look up infrastructure associated with scanning, proxies and DDoS activity.
- [MITRE ATT&CK](https://attack.mitre.org/) - Map observed adversary behavior to documented tactics and techniques.
- [Malpedia](https://malpedia.caad.fkie.fraunhofer.de/) - Look up malware families, aliases and research references.
- [MISP](https://www.misp-project.org/) - Correlate threat indicators and share intelligence with trusted communities.

## Phishing and spam
